# Internationalization

A single English locale (`i18n/en_us.mbt`) providing item display name overrides.

## Name Resolution

`item_display_name(name)` follows this logic:
1. If the name matches a hardcoded override (e.g., "grass" → "Grass Block", "sandstone_carved" → "Chiseled Sandstone"), return the override
2. Otherwise, humanize the name by splitting on underscores, capitalizing each word
3. Append a generation suffix for prefixed IDs: "(Classic)" for `classic.*` names, "(pre-Classic)" for `pre-classic.*` names

This ensures mined blocks and inventory items show human-readable names regardless of their internal string ID.

**WIP**: Only English is implemented. There is no locale selection, no pluralization, no gender forms, and no translation framework — only a fixed override map.
